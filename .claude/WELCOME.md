## Claude Agent Kit {{VERSION}}

Набор помощников с чёткими ролями. Задача идёт по конвейеру — **исследование → план →
реализация → проверка**, — и на ключевых шагах останавливается, чтобы решение приняли вы.
Менять код может только один помощник и только по утверждённому вами плану.

**Сейчас в наборе:** {{AGENTS}} помощников, {{COMMANDS}} команд.
**Профиль проекта:** {{PROFILE}}

### С чего начать

| Команда | Когда нужна |
|---------|-------------|
| `/cckit_feature <задача>` | новая функция или заметное изменение — полный конвейер |
| `/cckit_quick <мелочь>` | понятная мелкая правка — короткий путь |
| `/cckit_help` | полный список команд |

Нужен только один шаг — вызовите помощника напрямую: `/cckit_explore` (разобраться),
`/cckit_plan` (план), `/cckit_review` (проверить), `/cckit_docs` и `/cckit_faq` (описать).
