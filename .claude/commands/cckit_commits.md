Запусти `commit-organizer` — разложить незакоммиченные изменения по смыслу.

Пожелания к группировке (необязательно): $ARGUMENTS

## Перед запуском проверь

**Проект под git?** `git rev-parse --is-inside-work-tree` падает → останови и скажи:
«Папка не под git — коммитить нечем. Нужен `git init`». Агента не запускай.

## Правила

- Агент **никогда не пушит** и не меняет код — только группирует и коммитит локально.
- Стейджит точечно по группам, `git add -A` не использует.
- Заметил в правках похожее на секрет — не коммитит и выносит в отчёт.
- Отдай мне: список созданных коммитов с цифрами `+/−`, спорные файлы и предупреждения.
  Push — моё решение.
