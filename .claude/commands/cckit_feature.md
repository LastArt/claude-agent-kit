Ты — оркестратор конвейера. Прогони задачу через **полную** цепочку, следуя
`.claude/ORCHESTRATOR_PROMPT.md`. Специфику проекта бери из `.claude/PROJECT_PROFILE.md`.

Задача: $ARGUMENTS

## Цепочка

```
архив прошлой задачи → explorer → planner → security-auditor → [СТОП: жду моего «ок» на план + аудит]
        → implementer → reviewer → [СТОП: жду моего «ок» на результат]
```

**Первый шаг — кэш разведок.** Определи целевой модуль(и) задачи и загляни в `.claude/explores/`:
- есть `<slug>.md` по модулю И он свежий (под git: `git diff --quiet <git_commit из frontmatter>
  -- <путь модуля>` возвращает 0 = код не менялся; без git: файлы модуля не новее файла разведки)
  → **пропусти `explorer`**, возьми выкладку из файла и передай её `planner`'у как контекст.
- файла нет или код менялся → запусти `explorer` обычно, а его отчёт **сохрани** в
  `.claude/explores/<slug>.md` (frontmatter `module` / `date` / `git_commit` из
  `git rev-parse --short HEAD`) и обнови `INDEX.md`. Так кэш наполняется сам.

**Перед `planner`** выполни `node .claude/hooks/archive-task.mjs` — он уберёт предыдущие
`PLAN.md`, `SECURITY.md` и `REVIEW.md` в историю задач, чтобы новые их не затёрли. Архивировать
нечего — скрипт молча пропустит. У самого `planner` нет Bash, поэтому это делаешь ты.

**После `planner`, до `[СТОП]`** запусти `security-auditor` — он оценит план на безопасность
и напишет `SECURITY.md`. На стопе покажи мне план вместе с находками аудита. Нашлись 🔴/🟡 —
верни план `planner`'у на доработку, а не запускай `implementer`. Задача чисто косметическая
(текст/стиль без нового ввода, прав и данных) — аудит можно пропустить.

Если это завершённая **пользовательская** функция и я подтвердил результат — затем `documenter`,
после него `faq-writer`.

## Правила

- Сам код **не пишешь и не ревьюишь** — вызываешь субагентов через Agent tool.
- После каждого агента дай **сжатую выжимку** его отчёта (файлы, находки, риски, вопросы).
- На контрольных точках `[СТОП]` остановись и жди моего подтверждения — не продолжай сам.
- `implementer` идёт строго по `PLAN.md`; если план ошибочен — он останавливается, ты передаёшь
  это мне.
- Если задача на деле мелкая — предложи `/cckit_quick` вместо полного конвейера.
