Покажи справку по набору. **Список команд не бери из памяти — собери из файлов**, иначе он
разойдётся с реальностью.

## Как собрать справку

1. Прочитай `.claude/VERSION` (если файл есть) — это версия набора.
2. Перечисли файлы `.claude/commands/*.md`, у каждого возьми имя файла и поле `description`
   из front-matter. Это и есть полный список команд — ничего не добавляй от себя и не
   выдумывай команд, которых нет среди файлов.
   - Файла `.claude/commands/` не видно (мы не в проекте с набором) — покажи только три
     глобальные команды: `/cckit_new-project`, `/cckit_install`, `/cckit_help`, и скажи,
     что остальные появятся в папке с развёрнутым набором.
3. Раздели их на три группы:
   - **Развернуть набор:** `cckit_new-project`, `cckit_install`, `cckit_research`
   - **Работа над задачей:** `cckit_feature`, `cckit_quick`
   - **Отдельные помощники:** все остальные `cckit_*` (по одному на агента)
4. Выведи таблицей: команда → что делает (из `description`).

## Добавь после таблицы

**Как идёт работа**

- `/cckit_feature`: исследователь → планировщик → **[подтверждение плана]** → исполнитель →
  ревьюер → **[подтверждение результата]**.
- `/cckit_quick`: планировщик → **[быстрое подтверждение]** → исполнитель → короткая проверка.
- Отдельные команды запускают ровно одного помощника и останавливаются — удобно, когда нужен
  только план, только ревью или только документация.

Код меняет только исполнитель и только по утверждённому плану. Подробные цепочки и режимы —
в `.claude/ORCHESTRATOR_PROMPT.md`.

**Настройка**

- Подтверждение правок: по умолчанию Claude Code спрашивает перед каждой правкой файла;
  `Shift+Tab` переключает на автоматический приём.
- Специфика проекта (команды, пути, стиль): `.claude/PROJECT_PROFILE.md`.
- Прочие настройки экземпляра: `.claude/CUSTOMIZE.md`.
- Проверить, что работает проверка синтаксиса: `node .claude/hooks/check-syntax.mjs --selftest`.

**Если команды не появились** — не запускали установщик или не перезапускали VS Code целиком
(`/clear` настройки не перечитывает).

Ничего не выполняй и не меняй — только выведи справку.
