Собери карту проекта и открой её в браузере. Всю работу делает хук `map.mjs` — ты запускаешь
его, коротко объясняешь результат и подсказываешь, как читать.

## Действуй так

1. Запусти сборку с открытием в браузере:

   ```
   node .claude/hooks/map.mjs --open
   ```

   Человек попросил уточнений (например «за последний год», «покажи и папку кита») — добавь ключи:
   - `--commits N` — сколько последних коммитов взять (по умолчанию 400);
   - `--depth K` — до какого уровня пути схлопывать файлы в модуль (1 — крупные области, 2 —
     по умолчанию, 3 — подробно);
   - `--files N` — сколько самых важных файлов оставить на файловом уровне (по умолчанию 200);
   - `--max-nodes N` — то же для уровня папок (по умолчанию 250);
   - `--bulk N` — коммит с бо́льшим числом файлов связей не даёт (по умолчанию 25);
   - `--with-kit` — не прятать служебную папку `.claude/`;
   - `--no-code` — не вшивать содержимое файлов (карта уедет наружу — код останется дома);
   - `--out ПУТЬ` — сохранить карту в другое место.

2. **Вставь вывод хука в ответ как есть** — там честно сказано, сколько коммитов просмотрено,
   сколько массовых пропущено и сколько связей не поместилось.

3. Скажи своими словами, что получилось: сколько модулей, какие правятся чаще всего
   (это видно в выводе `--json`, если понадобится), есть ли подсветка задач.

## Что важно объяснить, если спрашивают

- Карта построена **не по импортам кода**, а по тому, что люди правят вместе: связь = «эти
  модули попадали в один коммит или в одну задачу кита». Часто это честнее схемы зависимостей —
  видно реальное сцепление, включая то, о котором в коде не написано.
- Оранжевые связи пришли из `.claude/artifacts/history/` (задачи кита), серые — из `git log`.
  Пустой список задач — нормально: он наполняется, когда задачи проходят через конвейер.
- У карты **три уровня** — папки, файлы и память; переключатель на самой странице, пересобирать
  не надо. На уровне файлов показаны самые важные: важность = как часто правят + сколько задач
  через файл прошло. Форма значка означает тип файла, цвет — папку, в которой он лежит.
- Двойной клик по файлу открывает **сам файл** прямо в карте: исходник — с номерами строк,
  markdown — отрисованным документом. Содержимое вшито в страницу, поэтому карта с кодом внутри:
  если её собираются кому-то переслать, предложи ключ `--no-code`.
- **Память** — это архив задач (`artifacts/history/`) и кэш разведок (`explores/`): узлы связаны
  общими файлами, общим модулем и общей темой. Двойной клик по записи открывает её целиком —
  markdown отрисуется как документ, никуда уходить не надо. Память пуста, пока через конвейер
  не прошло ни одной задачи, — это нормально, так и скажи.
- Файл `.claude/map.html` самодостаточный: данные вшиты внутрь, интернет и сервер не нужны,
  его можно переслать или положить в вики. Он не обновляется сам — это снимок на момент сборки,
  пересобрать = запустить команду снова.

## Границы

- Ничего не правь в проекте руками: карта — это только чтение git и архива задач.
- `node` не найден → скажи, что без Node карта не соберётся, и не пытайся рисовать её текстом.
- Карта пустая (нет ни коммитов, ни истории) → так и скажи, предложи вернуться, когда появятся
  коммиты или пройдёт первая задача через `/cckit_feature`.
