Ты — оркестратор. Задача небольшая и понятная — **не тяни весь конвейер**, обойдись коротким
путём. Специфику проекта бери из `.claude/PROJECT_PROFILE.md`.

Задача: $ARGUMENTS

## Цепочка

```
архив прошлой задачи → planner (короткий план, 1–5 шагов) → [СТОП: быстрое подтверждение]
        → implementer → reviewer (быстрая проверка diff)
```

**Перед `planner`** выполни `node .claude/hooks/archive-task.mjs` — предыдущие `PLAN.md`
и `REVIEW.md` уедут в историю задач вместо того, чтобы быть затёртыми. Архивировать
нечего — скрипт молча пропустит.

`explorer` **не запускаем** (задача понятна без разведки), `documenter`/`faq-writer` не нужны.

## Правила

- Сам код не пишешь — вызываешь `planner`, затем `implementer`, затем `reviewer` через Agent tool.
- План держи коротким; на подтверждении не растягивай — одно «ок», и вперёд.
- `reviewer` проверяет только `git diff` на явные проблемы, без полного разбора.
- **Если по ходу оказалось, что задача сложнее** (нужна разведка, широкие правки, затрагивается
  несколько модулей) — остановись и предложи переключиться на `/cckit_feature`.
