Ты — оркестратор. Задача небольшая и понятная — **не тяни весь конвейер**, обойдись коротким
путём. Специфику проекта бери из `.claude/PROJECT_PROFILE.md`.

Задача: $ARGUMENTS

## Цепочка

```
новая задача (task.mjs new) → planner (короткий план, 1–5 шагов) → [СТОП: быстрое подтверждение]
        → implementer → reviewer (быстрая проверка diff) → task.mjs close
```

**Перед `planner` заведи задачу.** `$ARGUMENTS` в команду **не подставляй** — собери из него
заголовок (оставь буквы, цифры, пробел, дефис, точку и запятую; остальное выбрось; переводы
строк замени пробелом; обрежь до 120 символов) и передай его **одним аргументом**:

```bash
node .claude/hooks/task.mjs new "<очищенный заголовок>"
```

Команда напечатает id и абсолютный путь к папке задачи. **Запомни этот путь и передавай его
каждому агенту в тексте вызова** — у `planner` нет Bash, сам он его не добудет; забыл — путь
даёт `node .claude/hooks/task.mjs path`. Статусы переключай сам —
`node .claude/hooks/task.mjs status <статус>`, — а после моего «ок» на результат закрой задачу:
`node .claude/hooks/task.mjs close`.

`explorer` **не запускаем** (задача понятна без разведки), `documenter`/`faq-writer` не нужны.

## Правила

- Сам код не пишешь — вызываешь `planner`, затем `implementer`, затем `reviewer` через Agent tool.
- План держи коротким; на подтверждении не растягивай — одно «ок», и вперёд.
- `reviewer` проверяет только `git diff` на явные проблемы, без полного разбора.
- **Если по ходу оказалось, что задача сложнее** (нужна разведка, широкие правки, затрагивается
  несколько модулей) — остановись и предложи переключиться на `/cckit_feature`.
