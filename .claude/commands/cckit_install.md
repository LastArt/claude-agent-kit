Разверни Claude Agent Kit в ТЕКУЩИЙ существующий проект в режиме **дополнения (additive)**.

## Где взять файлы кита (источник)

Проверь по порядку и возьми ПЕРВЫЙ существующий:

1. `~/.claude/agent-kit/` — установленный мастер-кит (на Windows
   `%USERPROFILE%\.claude\agent-kit`). Домашнюю папку определи сам, не хардкодь чужой путь.
2. Папку набора, если пользователь указал её явно.

Если мастер-кит не найден — остановись и скажи: «Кит не установлен. Запусти `install.ps1`
(Windows) или `install.sh` (Linux/macOS) из папки набора, затем полностью перезапусти
Claude Code». Ничего не копируй.

## Действуй так

0. **Проверка: не в папке-исходнике кита.** Если в корне текущей папки есть одновременно
   `install.ps1` и `install.sh` — это исходники самого набора, а не проект. НЕ разворачивай сюда.
   Остановись и скажи: «Это папка с исходниками набора, а не проект. Открой Claude Code в папке
   реального проекта». Ничего не копируй и не создавай.

1. `имя проекта = имя текущей папки`. Целевая папка = текущая директория. Покажи путь.

2. **Скопируй кит** из источника в `./.claude/`, **НЕ перезаписывая существующие файлы.**
   Если уже есть `.claude/settings.json`, свои агенты в `.claude/agents/`, заполненный
   `PROJECT_PROFILE.md`, `PLAN.md`/`REVIEW.md` с содержимым — **пропусти их**.
   Никогда не копируй `settings.local.json` (локальные разрешения чужой машины) и
   `CLAUDE.md` из папки `.claude/` (инструкции по разработке самого набора).
   Есть `PROJECT_PROFILE.template.md`? Значит, соседний `PROJECT_PROFILE.md` — чужой
   заполненный профиль: клади шаблон под именем `PROJECT_PROFILE.md`, а сам файл шаблона
   в проект не тащи.

3. **КРИЧИ О ПРОПУЩЕННОМ.** Всё пропущенное выведи явным блоком-предупреждением:
   «⚠ НЕ ТРОНУТЫ (уже есть — перезапись убила бы наработки): …», списком. Тихо клоббернуть
   настройки проекта нельзя.

4. `CLAUDE.md` **не создавай, если он уже есть.** Если его нет — не выдумывай, соберёт
   `/cckit_research` из разведки репозитория.

5. В `PROJECT_PROFILE.md` (только если ты его сейчас создал, а не пропустил) подставь имя.

6. **Закрой файлы набора от репозитория проекта.** Набор — инструмент на машине человека,
   а не часть его продукта: по умолчанию он не должен попадать в репозиторий и уезжать
   на удалёнку. Допиши в `.gitignore` проекта (создай файл, если его нет; блок уже есть —
   не дублируй):

   ```
   # Claude Agent Kit — служебные файлы помощников, остаются на этой машине.
   # Поделиться набором с командой осознанно: /cckit_push-with-me
   .claude/
   # Результаты прогона проверок, подтверждение набора команд и состояние гейта: остаются
   # на этой машине, даже если строка .claude/ выше будет убрана.
   .claude/artifacts/VERIFY.json
   .claude/artifacts/VERIFY.lock
   .claude/artifacts/GATE_STATE.json
   ```

   Часть файлов `.claude/` **уже отслеживается** в этом репозитории (кто-то закоммитил их
   раньше) — не удаляй их из индекса молча. Скажи об этом человеку и предложи решение:
   оставить как есть или выполнить `git rm --cached -r .claude/`.

7. **Запиши реестр установленных файлов.** Выполни `node .claude/hooks/write-manifest.mjs` —
   он создаст `.claude/.cckit-manifest.json` (для `/cckit_uninstall`). В реестр попадают только
   файлы кита; чужие файлы, уже лежавшие в этом проекте, он не считает своими и не тронет.
   `node` не найден — пропусти, скажи одной строкой, что реестр не создан.

8. **Поздоровайся и проверь, что всё живо:**
   - выполни `node .claude/hooks/banner.mjs --welcome` и вставь полученный markdown в ответ
     **как есть, не оборачивая в блок кода** — иначе логотип не отрендерится;
   - следом выполни `node .claude/hooks/check-syntax.mjs --selftest` и покажи результат
     одной-двумя строками, оформив эмодзи: ✅ всё зелёно (exit 0, ошибок нет); ❌ тест упал
     или есть ошибки (назови, что); ⚠️ на что обратить внимание (напр.: для языка проекта
     проверка на этой машине недоступна — скажи прямо, не замалчивай).

9. **Доложи:** что добавлено, что пропущено. Затем дословно:
   «Набор установлен в проект. Дальше:
   1) Полностью перезапусти Claude Code (чтобы подхватились команды набора).
   2) Выполни `/cckit_research` — набор изучит проект и подстроится под него.»

Ты только раскладываешь недостающие файлы — **прод-код не трогаешь, существующее не затираешь**.
