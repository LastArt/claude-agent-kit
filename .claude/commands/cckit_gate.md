---
description: Открыть меню проверки перед сдачей — включить, выключить, подтвердить список
---

Открой человеку **меню приёмки в отдельном окне терминала**. Сам ничего не настраивай:
подтверждение списка команд и снятие гейта — его решения, и делаются они руками.

## Действуй так

1. Открой окно одной командой — она сама знает, как это делается на каждой системе:

   ```
   node .claude/hooks/gate-menu.mjs --launch
   ```

   Команда возвращается сразу: окно живёт своей жизнью. Не жди его и не пытайся вычитать
   оттуда вывод — человек работает в нём сам, а ты в это время свободен. Платформенную возню
   (заголовок окна, выбор терминала на Linux, `open -a Terminal` на macOS) хук берёт на себя;
   вручную `start` и его родню не зови — из Git Bash это открывает пустое окно.

2. Скажи одной-двумя строками, что открылось окно и что в нём: состояние приёмки сверху,
   дальше пункты по цифрам — показать список проверок, подтвердить его, прогнать проверки,
   включить или выключить слежение, открыть файл со списком, короткая справка.

3. Окно открыть не удалось (нет графической среды, ssh-сессия) → **не пытайся сделать всё сам**.
   Скажи, что запустить руками: `bash .claude/gate.sh` на macOS/Linux, `.claude\gate.bat`
   на Windows — двойным кликом из проводника тоже работает.

## Если человек хочет без окна

Спросил коротко «что там с проверками?» — можно ответить прямо здесь:

```
node .claude/hooks/verify.mjs --selftest
node .claude/hooks/gate.mjs --status
```

Переведи вывод человеческими словами: сколько проверок настроено, подтверждены ли они,
следит ли гейт за задачей сейчас. Всё, что **меняет** состояние — подтверждение, включение,
выключение — только через окно.

## Границы

- `--accept` и `--disarm` за человека не выполняй: первое физически требует терминала,
  второе — его решение.
- `.claude/settings.json` не трогай, он закрыт правами намеренно.
- Нет Node — скажи прямо: без него приёмка не работает вовсе.
