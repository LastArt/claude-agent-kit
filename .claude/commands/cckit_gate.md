---
description: Проверка перед сдачей — состояние приёмки, включить, выключить, прогнать
---

Покажи человеку, что сейчас с машинной приёмкой, и помоги ей управлять. Работай по режиму
из аргумента: $ARGUMENTS

Пустой аргумент — покажи **состояние**. Дальше по словам:
`вкл` / `on` — взвести, `выкл` / `off` — снять, `проверь` / `check` — прогнать проверки,
`покажи` / `show` — показать список команд из профиля.

## Состояние (по умолчанию)

Выполни и покажи вывод как есть:

```
node .claude/hooks/verify.mjs --selftest
node .claude/hooks/gate.mjs --status
```

Затем объясни **своими словами и без терминов**, что из этого следует. Ориентиры:

- проверок настроено 0 → «приёмка выключена: список проверок пуст, всё работает как обычно.
  Хотите включить — впишите проверки в `.claude/PROJECT_PROFILE.md`, раздел «Команды проекта»»;
- проверки есть, подтверждения нет → «список составлен, но не подтверждён, поэтому не выполняется.
  Подтвердить может только человек и только в терминале: `node .claude/hooks/verify.mjs --accept`»;
- гейт не взведён → «сейчас за ходом никто не следит, это нормальное состояние между задачами»;
- взведён и `verify: pass` → «последний прогон зелёный»;
- статус `blocked` → «приёмка трижды не прошла, дальше решает человек» — и назови, что упало.

## Включить (`вкл`)

```
node .claude/hooks/gate.mjs --arm "<название текущей задачи>"
```

Скажи прямо: пока гейт взведён, проверки прогоняются в конце **каждого** хода, и если они
красные — ход не завершается. Три неудачи подряд снимают блокировку сами и зовут человека.

## Выключить (`выкл`)

**Сам не выключай — это действие человека.** Напечатай команду и попроси выполнить её в терминале:

```
node .claude/hooks/gate.mjs --disarm
```

Если попросят «выключить совсем, а не на задачу» — покажи рычаги из `.claude/CUSTOMIZE.md`,
раздел «Машинная приёмка»: пустой `checks:` в профиле отключает приёмку в проекте,
`CCKIT_GATE=off` — на одну сессию, `settings.local.json` с `disableAllHooks` — аварийно.

## Прогнать (`проверь`)

```
node .claude/hooks/verify.mjs
```

Вставь вывод как есть и переведи итог: `pass` — прошло всё, `partial` — часть проверок
пропущена (например, нет нужной программы), `fail` — упало, назови какая проверка и почему.

## Показать список (`покажи`)

```
node .claude/hooks/verify.mjs --show
```

Печатает команды и их отпечаток, ничего не записывая. Полезно перед подтверждением: человек
видит, что именно будет выполняться у него на машине.

## Границы

- Подтверждение (`--accept`) и снятие (`--disarm`) — **только человек, только терминал**.
  Не пытайся выполнить их за него и не предлагай обходных путей.
- `.claude/settings.json` не правь: он закрыт правами, и это намеренно.
- `node` не найден → скажи, что без Node приёмка не работает, и остановись.
