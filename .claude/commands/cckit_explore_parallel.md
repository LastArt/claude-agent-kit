Запусти несколько `explorer`'ов **ПАРАЛЛЕЛЬНО** (по одному на область), сведи отчёты и **сохрани
разведку каждого модуля в кэш `.claude/explores/`** — чтобы конвейер потом переиспользовал её
и не разведывал заново.

Области (через запятую): $ARGUMENTS

## Как выполнять

1. **Разбери аргумент.** Раздели `$ARGUMENTS` по запятым → список областей (модули, папки, темы).
   Пусто — спроси, что разведать, и остановись.
2. **Запусти explorer'ов ОДНИМ ходом = параллельно.** В одном ответе вызови Agent tool **по разу
   на каждую цель** (несколько вызовов в одном сообщении → идут одновременно). Каждому — узкое
   задание: «разведай <область>, верни отчёт». Профиль проекта агент читает сам.
3. **Дождись всех.** Отчёты вернутся вместе.
4. **Сохрани каждую разведку в кэш** `.claude/explores/` (создай папку, если её нет):
   - имя файла — slug пути модуля (`/`→`__`), напр. `contracts__smartcut_module.md`;
   - в начало файла — frontmatter:
     ```
     ---
     module: <точный путь/имя области>
     date: <ГГГГ-ММ-ДД>
     git_commit: <короткий HEAD: git rev-parse --short HEAD; нет git — поле пропусти>
     ---
     ```
   - ниже — выкладку этого explorer'а целиком;
   - допиши строку в `.claude/explores/INDEX.md`: `- **<модуль>** — <дата> — <git_commit>`.
5. **Отчитайся:** по каждой области — суть, плюс раздел **«Связи между модулями»**. Скажи, что
   разведки сохранены в кэш и конвейер (`/cckit_feature`) их подхватит без повторной разведки.

## Правила

- Explorer — **read-only**; файлы в кэш пишешь **ты (оркестратор)**, не он.
- Только **независимые** области. Планов и кода нет — нужен план, человек скажет `/cckit_plan`.
- `.claude/explores/` — стоячий кэш, общий на проект: он живёт не в папке задачи
  и с её завершением никуда не девается. Обнулить можно удалением файла или всей папки.
