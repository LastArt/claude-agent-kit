description: Заново разместить инструкцию на рабочем столе (если ярлык потерян) и открыть её
---

Пересоздай страницу-инструкцию Claude Agent Kit и положи на рабочий стол фирменный ярлык,
открывающий её в браузере по умолчанию.

## Действуй так

1. Найди скрипт сборки: `~/.claude/agent-kit/hooks/make-guide.mjs`
   (на Windows `%USERPROFILE%\.claude\agent-kit\hooks\make-guide.mjs`; домашнюю папку определи
   сам, не хардкодь чужой путь).

2. Если файла нет — значит набор не установлен как мастер. Скажи: «Набор не установлен.
   Запусти `install.ps1` (Windows) или `install.sh` (Linux/macOS) из папки набора». Больше ничего.

3. Если есть — выполни его через Bash с флагом `--open`:
   `node "<путь>/make-guide.mjs" --open`
   Скрипт сам соберёт самодостаточную `guide.html`, положит ярлык на рабочий стол
   (Windows `.url` с иконкой, macOS `.webloc`, Linux `.desktop`) и откроет страницу в браузере.
   Рабочий стол он определяет сам (в т.ч. перенаправленный в OneDrive).

4. Покажи пользователю вывод скрипта (путь к инструкции и к ярлыку) и скажи, что страницу
   всегда можно открыть двойным кликом по ярлыку «Claude Agent Kit» на рабочем столе.

Ничего не меняешь в проекте — только собираешь инструкцию.
