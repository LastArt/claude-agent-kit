# Кэш разведок (explores)

> Разведки модулей, сохранённые `/cckit_explore_parallel` (и конвейером при обычной разведке).
> Конвейерный `explorer` проверяет этот кэш **первым**: есть свежий файл по модулю — разведка
> пропускается, задача сразу уходит планировщику. «Свежий» = код модуля не менялся с `git_commit`
> разведки (под git — `git diff`; без git — по времени файлов).
>
> Пополняется автоматически. Один файл = один модуль (`<slug>.md`, `/`→`__`).
